Edit squares — one mode for boxes and numbers per square (idea-258)

Study docs/prds/square-edit-mode.md. One screen (Modal Manager square-edit), one pure module (utils/squareEdit.ts), opened with the row as input from the Stock card, item detail and Move. Solid = what the database says today. Dashed = what the rule would put (or units no box covers). Amber = pending until SAVE. Square figure 56 px, pallet number 28 px, every target ≥ 48 px. All rows and every neighbour figure in the strips are real (prod, 7 Oct 2026; a square shared by several SKUs shows their total, a row never split shows its even share).
