PickD — What's new

Thursday, September 17, 2026 · for everyone on the Ludlow floor

The short version

1. Cancelling a combined order now cancels every order on the card, and the units it gives back match the number the card was showing.

2. An order that is already finished no longer changes carrier by itself.

What you will notice

1. Cancelling a combined order now cancels the whole pallet.

Orders that were combined show up in Ship as one card: the order numbers across the top, and one row of numbers underneath that adds up all of them. Cancel Order on that card only cancelled one of them — the oldest — and the message it gave back was easy to read as normal:

Before: the card said 8 units · the message said "Order cancelled — 5 units to RETURN TO STOCK"

The rest of the card stayed exactly as it was: finished, waiting to ship, with its bikes still counted as picked. On two cards today that came to 8 bikes of JAX OUTDOOR GEAR that PickD had already taken off the shelves and that no longer belonged to any order — 3 FAULTLINE A3 V2 17 from ROW 34, 2 FAULTLINE A3 V2 19 from ROW 38, a HELIX 16 from ROW 2, a Helix 18 from ROW 8, and a RENEGADE A1 LTD 51 from ROW 25. Stock that is not on the shelf sends the next picker to an empty spot, and an order that reads as finished when nobody is going to ship it is one more thing to explain at the end of the week.

Fixing it by hand did not work either. Once the first order of a combined one had been cancelled, cancelling the second came back red — "Failed to cancel order: tuple to be updated was already modified…" — and nothing was returned.

Now the card is the pallet:

Now: "Mark all 3 orders of this combined order as cancelled?" → "3 orders cancelled — 8 units to RETURN TO STOCK"

The same number the card was showing. If any of those orders is marked as shipped it still asks first — the same Never shipped? question as before — and nothing is written until you answer it.

2. An order that is already finished no longer changes carrier by itself.

When one order left a combined group, the ones that stayed behind could switch from truck to FedEx on their own, including orders that were already verified and waiting to ship. That is how the pallet travels and what the station picks in Audit Source or in the FedEx system, so it was a decision nobody made. Orders that are still open are reclassified as before.

Coming up

  • Cancelled orders in Ship, and undoing a cancellation. Today a cancelled order cannot be seen in Ship at all, so bringing one back has to be done from the outside. The screen is being designed now: a filter to see them, and one action to undo the cancellation — the order goes back to finished and its units come off the RETURN TO STOCK pallet, because that is where they have been sitting all along.
